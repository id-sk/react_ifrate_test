# Checkbox

## Overview (Prehľad)

Komponent `Checkbox` umožňuje používateľovi vybrať alebo zrušiť výber jednej možnosti. Pre skupiny checkboxov slúži komponent `CheckboxGroup`. Podporuje dve veľkosti, pomocný text (`hint`), chybovú správu, tooltip a indeterminate stav pre hierarchické výbery.

## Prístupnosť (Accessibility)

- Každý checkbox je natívny `<input type="checkbox">` — prístupný cez Tab a Space
- `hint` a `errorMessage` sú prepojené cez `aria-describedby`
- Indeterminate stav nastavuje `aria-checked="mixed"` (spravované Radix UI primitívom)
- `CheckboxGroup` používa `<fieldset>` a `<legend>` pre správnu sémantiku skupiny

## Použitie

```tsx
import { Checkbox, CheckboxGroup } from '@idsk/core';

// Jednoduchý checkbox
<Checkbox
  label="Súhlasím s podmienkami"
  required
  hint="Prečítajte si podmienky pred odoslaním."
/>

// Skupina checkboxov
<CheckboxGroup legend="Obľúbené ovocie" hint="Vyberte aspoň jednu možnosť">
  <Checkbox label="Jablko" name="fruit" value="apple" />
  <Checkbox label="Banán" name="fruit" value="banana" />
  <Checkbox label="Pomaranč" name="fruit" value="orange" />
</CheckboxGroup>
```
