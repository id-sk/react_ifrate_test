## Overview (Prehľad)

Komponent `Radio` umožňuje používateľovi vybrať práve jednu možnosť zo skupiny. Pre skupiny radio buttonov slúži komponent `RadioGroup`. Podporuje dve veľkosti, pomocný text (`hint`), chybovú správu a tooltip.

## Prístupnosť (Accessibility)

- Každý radio button je natívny `<input type="radio">` — prístupný cez Tab a šípkové klávesy
- `hint` a `errorMessage` sú prepojené cez `aria-describedby`
- `RadioGroup` používa `<fieldset>` a `<legend>` pre správnu sémantiku skupiny
- Šípky ↑↓ alebo ←→ prepínajú výber medzi radio buttonmi v rámci skupiny

## Použitie

```tsx
import { Radio, RadioGroup } from '@idsk/core';

// Jednoduchý radio button
<Radio
  label="Možnosť A"
  name="moznost"
  value="a"
  required
  hint="Vyberte jednu z možností."
/>

// Skupina radio buttonov
<RadioGroup legend="Obľúbené ovocie" hint="Vyberte jednu možnosť">
  <Radio label="Jablko" name="fruit" value="apple" />
  <Radio label="Banán" name="fruit" value="banana" />
  <Radio label="Pomaranč" name="fruit" value="orange" />
</RadioGroup>
```
